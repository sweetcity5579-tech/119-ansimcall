# 119안심콜 홍보 사이트

시민용 QR 경로: /qr · 관리자: /admin.html

통계는 날짜별 접속·클릭 합계이며 고유 인원이나 가입 완료 수가 아닙니다. 앱은 방문자 IP·쿠키·개인별 접속기록을 저장하지 않습니다. Render 인프라 로그는 별도로 관리해야 합니다.

통계·비밀번호 해시는 COUNTER_DB의 SQLite에 저장합니다. Render 영구 디스크 /var/data를 연결해야 재배포 후 유지됩니다. ADMIN_TOKEN은 Render에서 생성하며 저장소와 로그에 출력하지 않습니다. 첫 로그인 때 Render Environment의 ADMIN_TOKEN 값을 확인하고 관리자 페이지에서 12~128자 비밀번호로 변경하세요. 변경 후 DB의 해시가 우선하며 환경변수로 덮어쓰지 않습니다.

DB를 공개 파일에 포함하지 않습니다. 디스크는 백업을 대체하지 않으며 영구 보존을 보장하지 않습니다. 운영 종료 전 SQLite 일관성 백업을 별도 보관해야 합니다.
